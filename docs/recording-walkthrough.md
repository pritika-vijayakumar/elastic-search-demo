## Rehearsal checklist

1. Run setup, ingestion, the live-answer check, and retrieval evaluation.
2. Confirm exact Jina endpoint/model and inspect actual vector settings. Update spoken
   default claims if your deployment differs; do not silently substitute a different model.
3. Inspect city-walking, exact-model, US 9 versus US 10, waterproofing, and guide retrieval.
4. Read the generated explanation for unsupported claims. Citation validation is not a
   factual-entailment guarantee. Confirm unknown waterproofing stays unknown.
5. Test a $1 budget and verify an honest no-match answer, not an invented recommendation.
6. Show latency as this run's timing, not a production SLA. Generation also incurs API usage.
7. Use the supplied tracking URLs and sponsorship wording in the post/editor workflow.
   The project does not invent tracking links or publish content.
